## Projects

### DEAF Framework
The Deaf Education Annotation Framework (DEAF) is a browser extension that lets Deaf learners annotate online content with South African Sign Language (SASL) videos. My capstone extends it from a Firefox desktop extension to mobile browsers, adding karaoke-style moving text highlights and subtitle integration synced to the SASL videos. Built as a community-based co-design process with Linguistics researchers, schoolteachers, and the lead DEAF developer, working directly with Deaf learners at the Dominican School for Deaf Children in Wynberg.

### WhatsApp Caregiver Survey Platform — Starting Chance NGO
Conversational survey system over WhatsApp for caregivers in Mfuleni township, supporting English, isiXhosa, and Afrikaans to remove literacy and language barriers. Led the Meta Cloud API integration and backend webhook handling, with data persisted in PostgreSQL via Supabase. Scoped as a pre-pilot MVP designed for handover, with documentation and architecture structured for future scaling.
